# Simulation Reports

Generated V2 deployed-vault simulation reports belong here.

Each run folder should contain:

- `usdc-buy-then-sell.json`;
- `direct-usdc-buy-approve-then-sell.json`;
- `otto-wallet-transfer-then-sell.json`;
- `direct-otto-wallet-approve-then-sell.json`;
- `otto-current-state-sell-negative.json`;
- `summary.json`.

Do not overwrite a report used for signoff. Create a new dated run folder.
