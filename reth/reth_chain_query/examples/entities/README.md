# Entity-Based Examples

This directory contains examples organized by entity type, demonstrating how to use the reth_chain_query library with different blockchain entities.

## Structure

- **etf/** - ETF and institutional holdings analysis
- **stablecoins/** - Stablecoin supply and market analysis
- **whales/** - Large holder tracking and analysis
- **cross_entity/** - Examples that combine multiple entity types

Each subdirectory contains focused examples for that entity type.
