# Stablecoin Examples

Examples for stablecoin market analysis:

- `stablecoin_supplies.rs` - Query total supplies of major stablecoins
- `stablecoin_market_share.rs` - Complete market share analysis
- `stablecoin_analysis.rs` - Comprehensive stablecoin ecosystem analysis
- `stablecoin_market_by_unit.rs` - Market analysis by accounting unit
