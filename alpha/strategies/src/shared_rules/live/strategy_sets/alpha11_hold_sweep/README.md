# Alpha11 Hold Sweep

Set name: `alpha11-live-univ2-lp30-pool-update-block-hold-sweep`

Expands to the Alpha11 live Uniswap V2 LP30 strategies with max hold windows of
12, 15, and 20 distinct pool-update blocks. The hold unit is not chain blocks;
it counts pool-update blocks observed while a position is open.
