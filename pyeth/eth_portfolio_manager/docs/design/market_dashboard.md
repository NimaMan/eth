# Market Dashboard Design Document

## 1. Market Overview
- **Total Tokens:** Count from tracked tokens using LiveTokenData.
- **Active vs. Inactive Tokens:** Determine using the trading_enabled flag and token_status.
- **Aggregated Trading Volume & Liquidity:** Summed values from sync events in token data.
- **Average Price Ratio:** Derived from the ratio of current to entry prices across tokens.

## 2. Risk and Scam Analysis
- **Scam Token Count:** Count tokens with status INACTIVE_SCAM.
- **Scam Probability Distribution:** Use the token_health_predictor outputs.

## 3. Trade Signal Metrics
- **Buy/Sell Signal Totals:** Count trade signals generated by strategy analysis.
- **Time-to-Trade Analysis:** Track time from token launch to trading_enabled events.

## 4. Network Dynamics & Temporal Trends
- **Block and Timestamp Trends:** Display synchronization with recent blocks.
- **Historical Trends:** Time-series charts for volume, liquidity, and signal occurrences.
