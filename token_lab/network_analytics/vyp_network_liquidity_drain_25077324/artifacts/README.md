# Artifacts

Generated data for the `vyp` network-liquidity-drain study belongs here.

Keep raw, large, or regenerated files out of normal commits unless they are
small enough to review or needed as regression fixtures.

Suggested subfolders:

- `chain_truth/`: RPC truth, block timestamps, code-kind checks, contract calls.
- `pool_reserves/`: reserve samples and reserve timeline exports.
- `token_network/`: first-order token graph summaries and selected seeds.
- `flow_context/`: fund-flow observations, edges, clusters, and suppressed hubs.
- `txs/`: decoded key transaction receipts, logs, traces, and method notes.
